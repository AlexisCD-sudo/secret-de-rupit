# El secret de Rupit

**El secret de Rupit** és un videojoc retro de tipus aventura/acció integrat en una sola pàgina web (HTML5 Canvas i JavaScript pur). 

## 🎮 Característiques

- **Estil Pixel Art:** Gràfics renderitzats directament sobre un Canvas de 256x192[cite: 1].
- **Sò :** Efectes de so generats mitjançant l'API d'àudio web (`AudioContext`)[cite: 1].
- **Controls Àmpliament Compatibles:** 
  - Compatible amb teclat per a ordinador.
  - Comandament virtual (joystick i botons mòbils) adaptat per a pantalles tàctils[cite: 1].
- **Disseny Adaptatiu (Responsive):** Ajustat per a pantalla completa i adaptat a orientació horitzontal en dispositius mòbils[cite: 1].

## 🛠️ Tecnologies Utilitzades

- **HTML5 & CSS3**[cite: 1]
- **JavaScript (ES6+)** sense llibreries externes[cite: 1]
- **Web Audio API**[cite: 1]
